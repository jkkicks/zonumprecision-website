github.com/jkkicks/Fusion-Free-Deburr · MIT · release v0.1.0-alpha.1, Nov 2026 · alpha — simulate before you cut

Fusion Free Deburr

Free 3-axis deburring toolpaths for Autodesk Fusion. Select edges, choose a ball or lollipop end mill, set the edge-break width, and generate. Lollipop mills can reach undercut rims; the add-in checks the cutter against the part and fixtures before it writes the toolpath. Right-click an operation and choose Edit Deburr to change it later.

github.com/jkkicks/cnckit · MIT · pip install cnckit

cnckit

A modular Python framework for job queuing, scheduling, and automation around LinuxCNC. The core has no dependencies — a FIFO/LIFO/priority queue, a scheduler with pause and resume, and a simulation mode so you can develop away from the machine. REST, MQTT, WebSocket, and ROS2 integrations are optional installs.
