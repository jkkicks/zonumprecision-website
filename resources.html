Fusion Free Deburr

Free 3-axis deburring toolpaths for Autodesk Fusion. Select edges, choose a ball or lollipop end mill, set the edge-break width, and generate. Edit the operation any time with right-click → Edit Deburr.

  • Ball & lollipop mills
  • Undercut rims with lollipops
  • Collision checks vs. part & fixtures
  • Built on Fusion's native Trace

cnckit

A lightweight, modular Python framework for job queuing, scheduling, and automation around LinuxCNC. Start with the dependency-free core and add only the integrations you need.

  • FIFO / LIFO / priority job queue
  • Scheduler with pause & resume
  • Simulation mode
  • REST, MQTT, WebSocket, ROS2
