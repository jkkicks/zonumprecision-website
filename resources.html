Free tools

Two tools I wrote for my own shop, one I forked and a web-app starter. All free on GitHub. Bug reports and pull requests are welcome.

Fusion Free Deburr

MIT · v0.1.0-alpha.1
Alpha: simulate before you cut

Free 3-axis deburring toolpaths for Autodesk Fusion. Select edges, choose a ball or lollipop end mill, set the edge-break width, and generate. Lollipop mills reach undercut rims, and the add-in checks the cutter against the part and fixtures before it writes the toolpath. To change an operation later, right-click it and choose Edit Deburr.

cnckit

Python · LinuxCNC · MIT
v0.2.0 · alpha

A modular Python framework for job queues, scheduling and simulation around LinuxCNC. The core has no dependencies. The queue runs FIFO, LIFO or by priority, the scheduler can pause and resume, and a simulation mode lets you develop away from the machine. REST, MQTT, WebSocket and ROS2 integrations are optional installs.

pip install cnckit
